ESP MIDI Bridge

ギターの音声 → MIDI → お気に入りの音源

シンセ音源を内蔵しない、音声からMIDIへの変換プラグインです。Windows x64のVST3対応DAWで使用します。

インストール後、最初にDAWでプラグインを再スキャンしてください。
VST3の場所：C:\Program Files\Common Files\VST3\ESP MIDI Bridge.vst3

v0.3.0は試用版です。FL終了処理が一度停止したため原因を確認中です。通常再生は再起動後に復旧しました。録音後の整理と自動起動の検証範囲はVERIFICATION.mdを参照してください。

FL Studioで接続する

  1. ギターを入力するMixerのエフェクトスロットに ESP MIDI Bridge を挿入します。
  2. Bridgeの MIDI DESTINATION を Host MIDI にします。Wrapperの歯車 → Settings → MIDI の Output port を、例えば 20 にします。
  3. Channel Rackに演奏したいVSTiを読み込みます。そのWrapperの Input portも20 にします。最初は送受信のMIDIチャンネルを1に合わせます。
  4. ギターを弾きます。Bridgeの入力メーターとノート名の変化を確認してください。音色と音量は受信側の音源で設定します。

MIDI Outプラグインを間に挟む必要はありません。20は例です。空いている同じポート番号に合わせてください。これはMIDIチャンネル番号とは別の設定です。

演奏モード

  • MONO：単音／最後に鳴った音を追います。MONO PITCHで LOOSE と STRICT を切り替えます。
  • POLY / experimental：最大6音の和音検出。MONOの品質選択は保持され、和音用の検出エンジンを使います。
  • チョーキング：MONO pitch bendをONにし、Bridgeと受信音源のベンド範囲を合わせます。最初は双方とも ±2半音。広いベンドは±12／24も選べます。
  • ギター音も聴く：Dry guitar monitorをONにします。初期値はOFFです。
  • PANIC：MIDIノートを止めます。ギターを一度ミュートし、入力がゲート以下になってから再演奏してください。

クリーン版MIDIを録音する（v0.3）

  1. Auto-save cleaned copyをONにし、BridgeのREC MIDIを押します。
  2. DAWでも必要な音声録音を開始して演奏し、BridgeのSTOP MIDIで停止します。
  3. ミュージックフォルダー内のESP MIDI Bridge/MIDI Takesへ-original.midと-clean.midを保存します。
  4. Drag clean MIDIを音源のPiano rollへドラッグして読み込みます。別名保存はSave cleaned...／Save original...、保存先はMIDI Takesから開きます。

短さ・強弱・前後の音程から疑わしい短いノートを整理します。演奏用MIDIは変えず、元データも残します。短い装飾音が消える可能性もあるので元データと聴き比べてください。FLの既存Piano rollへ直接録音したノートは自動で書き換えません。

このファイル録音はBridgeに内蔵され、loopMIDIなしでも動作します。FLではREC MIDI／STOP MIDIを使用してください。Follow DAW recordはホストが録音状態を通知する場合だけ動作します。

FLへ直接録音する場合・loopMIDIの自動起動

別途公式loopMIDIを初回インストールして専用ポートを作成します。BridgeをDevice MIDIにし、そのポートを選択。FLのMIDI settingsで同じInputをEnableにし、Notes録音を使います。

Auto-start installed loopMIDIをONにすると、インストール済みloopMIDIをバックグラウンド起動し、選択済みポートへ再接続します。loopMIDIの設定画面の×で閉じてもポートは動作し続けます。意図して終了する場合はAuto-startをOFFにしてください。ドライバーは同梱しません。

Host MIDIで同じ音源へ二重に送らないでください。音声はDAW側で録音します。録音の詳しい手順と制約。

他のDAW・MIDIポート

DAWがプラグインのMIDI出力を音源へ接続できる場合は、Host MIDIを使います。直接つなげない構成では、Device MIDIからOS側の仮想MIDIループバックポートへ送り、音源トラックのMIDI入力にそのポートを選ぶ方法があります。仮想MIDIドライバーはこのインストーラーには含まれません。

詳しい手順：DAW別接続ガイド。Cubase／Studio Oneの実機接続とmacOS／Logic用ビルドは未検証です。このインストーラーはWindows用です。

更新・削除

更新時もDAWを閉じてからセットアップを実行してください。削除はWindowsの「設定 → アプリ → インストールされているアプリ → ESP MIDI Bridge」から行います。ESP String Labや他の音源、DAWプロジェクトは削除しません。

English quick start

Rescan plugins, insert ESP MIDI Bridge on your guitar mixer track, and choose Host MIDI. In FL Studio, set the Bridge wrapper MIDI Output port to 20 and your VST instrument wrapper MIDI Input port to 20. Match MIDI channels and pitch-bend ranges (initially ±2 semitones). No MIDI Out plugin is required. MONO offers LOOSE and STRICT; POLY uses the experimental chord detector. Close your DAW before updating or uninstalling.
