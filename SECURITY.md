# Reporting security concerns

Report a suspected vulnerability privately using [GitHub's security advisory form](https://github.com/DTMgengen/esp-midi-bridge-vst3/security/advisories/new). Do not attach secrets, recordings, personal paths, full DAW projects or sensitive crash dumps to a public issue. If private reporting is unavailable, open a minimal issue asking for a private reporting channel without exploit or personal details.

The current 0.3.x preview is the focus of fixes. There is no guaranteed response time or security certification. See [privacy, permissions, distribution limits and safe routing](docs/PRIVACY_SECURITY.md).
